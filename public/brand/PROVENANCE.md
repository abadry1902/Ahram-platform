# Temporary logo assets

These four PNG files are copied byte-for-byte from the user-supplied `AL_AHRAM_Final_Acceptance_Handoff_Kit(1).zip` (2026-10-25). The kit explicitly authorizes temporary use, identifies them as **derived raster assets**, and leaves approval of the original master source pending. No tracing, recoloring, cropping, filtering or image generation was applied. Original dimensions and SHA-256 hashes are recorded in `lib/brand-assets.json`.

Light backgrounds use the supplied full-color asset; dark backgrounds use the supplied white/orange variant. `Brand` uses image elements with intrinsic dimensions and proportional CSS sizing. These are not original SVG/vector files and do not close the original-logo acceptance gate.
